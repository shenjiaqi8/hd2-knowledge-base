# Upload Data

**分类：** 战略配备 (`stratagems`) · **ID：** `upload-data`

**Wiki 原始词条：** https://helldivers.wiki.gg/wiki/Upload_Data

## 简介

The Upload Data Stratagem is used to start the data upload process. It's only available while near the Escape Pod from the Upload Escape Pod Data Objective.
